To be able to run the codes in this repository, create your virtual environment and install the required dependencies with the requirements file, such as follows:

1. Initialize the virtual environment
```bash
python -m venv venv
```

2. Install the necessary packages on the virtual environment:
```bash
pip install -r requirements.txt
```

This step is necessary due to version dependencies of the [Robotics Toolbox](https://petercorke.github.io/robotics-toolbox-python/), developed by Peter Corke.

The project of this repository is currently under development, some files may be unfinished.
